# 🖥️ Week 1 – RTL Design & Synthesis  

This repository captures everything I learned during **Week 1 of RTL design and synthesis training**.  
It covers the full flow from writing Verilog RTL to generating an optimized gate-level netlist using:

- **Icarus Verilog** – simulation  
- **GTKWave** – waveform analysis  
- **Yosys** – logic synthesis  
- **Sky130 PDK** – standard-cell libraries and timing data  

---

## ✨ What’s Inside
- 📂 **Day1-5/** – Detailed daily notes and labs  
- 📜 **readme.md** – Per-day explanations, lab descriptions, and key takeaways

## 🔑 Key Learning Highlights
- ✔️ Clean, synthesizable **Verilog RTL** with testbenches  
- ✔️ Simulation & waveform validation  
- ✔️ **Timing library (.lib)** usage for synthesis constraints  
- ✔️ **Combinational & sequential optimizations** for area, power, and performance  
- ✔️ Avoiding **simulation–synthesis mismatches** and unintended latches  
- ✔️ Scalable RTL using **for/generate** constructs
